Edushade runs a course business: the teaching, the learners, the money, and the website
that sells it.

If you are setting up for the first time, work through these in order. If you are
looking for one thing, use the search at the top — everything in this knowledge base is
in it.

## The shortest possible version

<Steps>

<Step>

### Set your academy up

Name, logo, domain, and how people sign in. See
[Your platform's identity](/docs/knowledgebase/account-people/your-platform-settings)
and [the Control Panel](/docs/knowledgebase/settings/control-panel).

</Step>

<Step>

### Build one course

Not five. One, finished properly, teaches you more than five half-built ones. See
[Creating a course](/docs/knowledgebase/courses/creating-a-course).

</Step>

<Step>

### Give it a price

Published is not for sale. See [Pricing](/docs/knowledgebase/selling-payments/pricing).

</Step>

<Step>

### Connect a payment service and an email service

Neither selling nor verification works without them. See
[Payment methods](/docs/knowledgebase/selling-payments/payment-methods) and
[Channels](/docs/knowledgebase/communication/channels).

</Step>

<Step>

### Buy it yourself

Register a fresh account and go through the whole thing. This finds the problems your
first real customer would have found. See
[Launch checklist](/docs/knowledgebase/start/launch-checklist).

</Step>

</Steps>

## Three things that trip up almost everybody

| | What happens |
|---|---|
| **A published course with no price** | It is in the catalogue and cannot be bought. |
| **A cohort-based course with no batch** | Nobody can enrol, because learners enrol into batches. |
| **Search indexing left switched off** | Your site is invisible, and nothing else you do for search matters. |
