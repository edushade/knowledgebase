## The things you build

| Word | What it means |
|---|---|
| **Course** | A unit of teaching. Self-paced or cohort-based. |
| **Batch** (cohort) | A scheduled run of a cohort-based course, with its own dates, seats, price and staff. The thing learners enrol into. |
| **Learning path** | Several courses as one programme, with one enrolment, one result and one certificate. |
| **Programme** | Any of the above, when it does not matter which. |
| **Stage** | A section in a learning path, holding whole courses. |
| **Section** | A container inside a course. |
| **Term** (breakpoint) | A dated slice of a batch — a semester. |
| **Bundle** | Several things sold together at one price. |
| **Product** | Something you sell that is not a course — a book or a guide. |

## Access

| Word | What it means |
|---|---|
| **Enrolment** | A learner's place in a programme. |
| **Partial access** (scope) | Holding part of a programme — one semester rather than four. |
| **Drip schedule** | **When** content opens. |
| **Prerequisite** | What must be finished before something opens. |
| **Eligibility rule** (access rule) | **Who** may see content at all. |
| **Transfer** | Moving a learner between batches, with or without their marks. |
| **Progression** | Deciding who moves up a semester. |

## Assessment

| Word | What it means |
|---|---|
| **Quiz** | A set of questions. |
| **Exam** | A quiz settled strictly. There is no separate exam object. |
| **Assignment** | Work a learner submits for marking. |
| **Attempt** | One sitting of an assessment. |
| **Alternative group** | Two or more interchangeable assessments counting as one slot. |
| **Merit list** | A ranked results sheet for one assessment. |
| **Leaderboard** | A ranking across a whole programme. |

## Grading

| Word | What it means |
|---|---|
| **Grading scheme** | The scale — bands, letters, grade points, the pass line. |
| **Weight** | How much an assessment counts. Weights total 100%. |
| **Result policy** | How a programme's result is formed. |
| **Rounding** | Which way a result goes when it will not fit — and, because bands are matched after rounding, where the pass line really is. |
| **Transcript** | The formal record of a result. |
| **Marksheet** | The simpler form — one line per subject. |

## Money

| Word | What it means |
|---|---|
| **Payment mode** | One-time, instalment or free. |
| **Payment method** | What the buyer uses — bKash, a card, cash. |
| **Payment gateway** | The service that processes it — SSLCommerz, Stripe. |
| **Instalment plan** (EMI) | Paying a fixed total over months. |
| **Offer** | A discount code. |
| **Scholarship** | A reduction granted to a named learner. |

## Communication

| Word | What it means |
|---|---|
| **Notice** | An announcement on the board. In-app only. |
| **Notification** | The platform telling somebody what happened to them. |
| **Campaign** | A message you wrote, sent to a group. |
| **Audience** (segment) | A group defined by conditions. |
| **Channel** | How a message travels — email, SMS, push, in-app. |

## Pairs people confuse

| | |
|---|---|
| **Drip** vs **eligibility** | *When* vs *who*. Drip shows a locked item with its date; eligibility shows nothing. |
| **Published** vs **for sale** | Publishing puts it in the catalogue. A price makes it buyable. |
| **Completion** vs **passing** | Did they do it, vs how well. |
| **Notice** vs **notification** | Your announcement vs something that happened to them. |
| **Method** vs **gateway** | What they paid with vs who processed it. |
| **Bundle** vs **learning path** | A price on several things vs one programme. |
| **Merit list** vs **leaderboard** | One assessment vs a whole programme. |
| **Transcript** vs **certificate** | What they achieved vs that they achieved it. |
