---

Most of the decisions later follow from one choice made now: what shape your teaching
is. Four shapes cover nearly everything.

## 1. A library of self-paced courses

People buy a course and start immediately. No dates, no batches.

| You need | Where |
|---|---|
| Self-paced courses | [Course types](/docs/knowledgebase/courses/course-types) |
| A price per course | [Pricing](/docs/knowledgebase/selling-payments/pricing) |
| Drip set to **After Enrollment**, if you pace it | [Drip scheduling](/docs/knowledgebase/enrollment-access/drip-scheduling) |

Simplest to run, and the one to start with if you are not sure.

## 2. Scheduled batches

Learners join a batch that starts on a date and moves together. Live classes,
deadlines, a cohort that finishes together.

| You need | Where |
|---|---|
| Cohort-based courses, with a batch per intake | [Cohorts and batches](/docs/knowledgebase/courses/cohorts) |
| A price per batch | [Pricing](/docs/knowledgebase/selling-payments/pricing) |
| Enrolment windows | [Enrolment windows](/docs/knowledgebase/enrollment-access/enrollment-windows) |
| Drip set to **Fixed Date** | [Drip scheduling](/docs/knowledgebase/enrollment-access/drip-scheduling) |

## 3. A diploma with semesters

A long programme divided into terms, where learners progress semester by semester and
may buy one at a time.

| You need | Where |
|---|---|
| A cohort-based course, or a learning path | [Learning paths](/docs/knowledgebase/courses/learning-paths) |
| Terms inside each batch | [Terms and semesters](/docs/knowledgebase/courses/terms-and-breakpoints) |
| A price per semester | [Partial access](/docs/knowledgebase/enrollment-access/partial-access) |
| Progression rules | [Progression](/docs/knowledgebase/enrollment-access/progression) |
| A grading scheme and weights | [Grading schemes](/docs/knowledgebase/progress-grading/grading-schemes) |
| Transcripts and certificates | [Certificates & Documents](/docs/knowledgebase/certificates) |

The most involved shape, and the one Edushade's grading, progression and transcript
features exist for.

## 4. A private or corporate academy

No public catalogue. You put learners in, and nobody buys anything.

| You need | Where |
|---|---|
| Site state **Private** | [Publishing your site](/docs/knowledgebase/website/publishing) |
| Self-registration off | [Accounts and sign-in](/docs/knowledgebase/account-people/accounts-and-sign-in) |
| Accounts you create | [Adding people](/docs/knowledgebase/account-people/adding-people) |
| Bulk enrolment | [Admin and bulk enrollment](/docs/knowledgebase/enrollment-access/admin-and-bulk-enrollment) |

## Mixing them

You can run more than one. A public self-paced library beside a private corporate
programme is common, and nothing in the platform objects.

What you cannot do is change a course's **type** after it is created — self-paced or
cohort-based is fixed. Choose it deliberately; everything else can be changed later.

## What Edushade does not do

Worth knowing before you plan around it:

| Not available |
|---|
| A shopping basket — one item per checkout |
| Automatic recurring billing from a stored card |
| Webcam proctoring or browser lock |
| Learner-to-learner messaging |
| Physical products, stock or shipping |
| A public certificate verification page |
