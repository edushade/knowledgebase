---
title: "Assessments & Quizzes"
description: "Quizzes, exams and assignments — building them, running them, and marking what comes back."
---

Everything a learner is tested on lives here. A **quiz** is a set of questions; an
**exam** is a quiz settled strictly; an **assignment** is work handed in for you to
read.

Two facts worth knowing before you start:

- **Ten question types work.** Six more appear in the picker and show *"not implemented
  yet"* — see [Question types](/docs/knowledgebase/assessments/question-types).
- **There is no webcam proctoring.** What you can do instead is on
  [Keeping an exam honest](/docs/knowledgebase/assessments/proctoring).
