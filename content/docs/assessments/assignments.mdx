title: "Assignments"
description: "Set tasks where learners submit text or files, then score them by hand with feedback — and feed the result into the course grade."
---

An assignment is a task you set for learners to complete and submit. Unlike most quiz
questions, assignments are graded by hand — you read each submission, give a score, and add
feedback. They are perfect for essays, projects, and file hand-ins.

## Types of assignment

| Type | What the learner does |
|---|---|
| **File upload** | Uploads one or more files (document, image, and so on). |
| **Text submission** | Writes their answer directly in a text box. |
| **Quiz-linked** | Completes a linked quiz as the assignment. |

A single assignment can accept text, files, or both.

## Creating an assignment

1. Go to **Admin → Assignments** (or add one inside a course) and click **New Assignment**.
2. Give it a **title** and **instructions** so learners know what to do.
3. Choose the **type** — file upload, text, or quiz-linked.
4. Set the **total marks** and the **passing marks**.
5. Set a **start date** and **end date** (the deadline).
6. Optionally set a **time limit** and a **maximum number of attempts** (leave blank for
   unlimited).
7. Attach any **supporting files** learners may need (a brief, a template, examples).
8. Optionally turn on **merit-list display** to rank submissions.
9. Save as **draft**, then **publish** when ready. You can **archive** it later.

## How learners submit

1. The learner opens the assignment and reads the instructions.
2. They write their text and/or upload their files.
3. They submit before the **deadline**.
4. If resubmission is allowed (within the attempt limit and before the deadline), each new
   submission counts as a **new attempt**.

## Grading an assignment

1. Open the assignment and pick a learner's submission.
2. Enter a **score** (it cannot exceed the total marks).
3. Add **feedback** and any **comments** for the learner.
4. Save. **Pass or fail** is worked out from the passing marks you set.

<Callout type="info">
The assignment score feeds into the learner's overall course grade. Decide how much it counts
using [weighted grading](/docs/knowledgebase/progress-grading/weighted-grading).
</Callout>

## What the learner sees

- The instructions, supporting files, total marks, and deadline.
- A place to type their answer and/or upload files.
- After grading: their score, pass/fail, and your feedback and comments.
- The merit list, if you turned it on.

## Good to know

<Callout type="warn">
Resubmissions only count while attempts remain **and** the deadline has not passed. Once the
end date arrives, no new submissions are accepted.
</Callout>
