---
title: "Exams"
description: "There is no separate exam feature — an exam is a quiz settled differently. Here is the recipe, and what learners see."
---

Edushade has no separate exam object. **An exam is a quiz** with its settings turned up:
one attempt, a real time limit, a narrow window, and results held until you release
them.

What makes it feel like an exam to a learner is the **Exam** area of their dashboard,
where assessments that are scheduled and count appear with their dates.

<WhoCan roles="Admin, Instructor" />

## Setting one up

<Steps>

<Step>

### Build the quiz

As normal — see [Creating a quiz](/docs/knowledgebase/assessments/creating-quizzes).
Give it a **Quiz Type** of "Exam" or "Final", so you can filter and report on exams
later.

Write real **Instructions**: what is allowed, what to do if something goes wrong, who to
contact.

</Step>

<Step>

### Settle the settings

| Setting | For an exam |
|---|---|
| **Maximum Attempts** | 1 |
| **Time limit** | On, with the real duration |
| **Allow Pause** | Off |
| **Shuffle questions** and **Shuffle answer options** | On |
| **Require All Questions** | On, if nothing may be skipped |
| **Pass Score** | Your pass mark |
| **Show answer after activity** | Off |
| **Show each learner's score as soon as they submit** | Off |
| **Release scores on** | After the window closes |

</Step>

<Step>

### Set the window

Add the quiz to the course and set its **Drip Schedule**: an **unlock** when the exam
opens and a **lock** when it closes. Without a lock there is no window, and a learner
sitting it two days later looks the same as one who sat it on the day.

See [Quiz availability](/docs/knowledgebase/assessments/quiz-availability).

</Step>

<Step>

### Decide what it is worth

On the programme's **Grading** tab, give the exam its weight. A final exam at 40% of the
course is a decision to make once, in the weights editor — see
[Weighted grading](/docs/knowledgebase/progress-grading/weighted-grading).

</Step>

</Steps>

## What the learner sees

The **Exam** area of their dashboard has three tabs:

| Tab | What is in it |
|---|---|
| **Upcoming Exams** | Scheduled, not yet sat. With **Starts At** and **Ends At**. |
| **Previous Exams** | Sat, with when they submitted and how long they took. |
| **Published Results** | Results that have been released. |

Each exam card carries its time limit, total questions, total marks, and — once
released — the score, the result and the accuracy rate, with a link to the
[merit list](/docs/knowledgebase/assessments/merit-lists).

Before release it reads **Under Review**. An exam they missed reads **Missed**, with the
deadline that passed. One not yet open reads **Locked**.

## On the day

- **Release the scores after the window closes**, not as learners submit.
- **Check the [analytics](/docs/knowledgebase/assessments/quiz-analytics) before you
  release.** A question almost everybody got wrong is usually a bad answer key, and it
  is much easier to fix before anyone has seen a mark.
- **Expect reschedules.** Somebody's connection will fail. See
  [Reschedules](/docs/knowledgebase/assessments/reschedules).

## What is not available

There is no webcam proctoring, browser lock or screen recording. See
[Keeping an exam honest](/docs/knowledgebase/assessments/proctoring) for what you can
actually do.

## Common questions

<Accordions type="single">

<Accordion title="Why does an exam show in the learner's Exam area and a quiz does not?">
The Exam area collects the assessments that are scheduled and count. A practice quiz
sitting inside a lesson is part of the course, not an exam.
</Accordion>

<Accordion title="A learner's exam says Under Review.">
They have submitted and the result has not been released — either marking is not
finished, or the release time has not come.
</Accordion>

<Accordion title="Can I run a makeup exam for the learners who missed it?">
Yes, and group it with the original so it satisfies the same slot. See
[Makeup assessments](/docs/knowledgebase/assessments/makeup-assessments).
</Accordion>

<Accordion title="Can two batches sit the same exam at different times?">
Yes. Availability belongs to the quiz item in each programme, so each batch gets its own
window.
</Accordion>

</Accordions>
