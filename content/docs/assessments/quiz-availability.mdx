---
title: "Quiz Availability"
description: "Decide when a quiz is open, protect it with a password, and limit how many learners can take it at once."
---

Availability settings control **when** a quiz can be taken and **who** can get in. Use them to
run a quiz only during a set window, lock it behind a password, or cap the number of
participants.

## Open and close times

Set a **start time** and an **end time** for the quiz:

- Before the start time, learners can see the quiz is coming but cannot begin.
- During the window, learners can take it (if they have access and attempts left).
- After the end time, the quiz closes and no new attempts can start.

This is ideal for a scheduled exam — for example, "open Sunday 10:00 AM to 12:00 PM".

<Callout type="info">
If a quiz lives inside a course, you can also tie its release to your course schedule. See
[Drip scheduling](/docs/knowledgebase/enrollment-access/drip-scheduling) and
[Exams](/docs/knowledgebase/assessments/exams).
</Callout>

## Password protection

Add a **password** so only learners who have it can start the quiz. Share the password at the
right moment — for example, read it out at the start of a live exam session — to control
exactly when people begin.

## Maximum participants

Set a **seat limit** to cap how many learners can take the quiz. Once the limit is reached, no
new learners can start. Useful for limited-capacity assessments or staggered sittings.

## What the learner sees

- Before it opens: the quiz appears but cannot be started yet.
- If a password is required: the learner is asked for it before the quiz begins.
- If seats are full: the learner is told it is not currently available.
- After it closes: the quiz is no longer open for new attempts.

<Callout type="warn">
A learner who is partway through an attempt when the close time arrives may be auto-submitted,
depending on your timer settings. Give a clear close time and a sensible grace period — see
[Quiz settings](/docs/knowledgebase/assessments/quiz-settings).
</Callout>
