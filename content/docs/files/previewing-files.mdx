---
title: "Previewing Files"
description: "Looking at a file without downloading it — what previews, what does not, and what learners see."
---

A preview opens a file in place. It saves downloading something to find out it is the
wrong one.

<WhoCan roles="Admin, Instructor, Learner" />

## What previews

| Type | In the file manager | In a lesson |
|---|---|---|
| **Images** | Yes | Yes |
| **Video** | Yes | Yes, in the player |
| **PDF** | — | Yes, in the reader |
| **Audio** | — | Yes, in the player |
| **Everything else** | Download it | Download it |

In the file manager, *"preview is only available for image and video files"*. Inside a
course, a **PDF lesson** opens in a reader — which is the reason to make a document a
PDF lesson rather than a file download when you want it read rather than kept.

## What learners get

| Content | How it opens |
|---|---|
| A **PDF lesson** | In the reader, with full screen. |
| A **video** or **audio lesson** | In the player, with their position remembered. |
| A **file item** | Opens for viewing, and can be downloaded. |
| An **attachment** | A download under the lesson. |

Where **Restrict paid content download** is on, paid content can be viewed and not
downloaded or printed. See
[Sharing and limits](/docs/knowledgebase/files/sharing-and-limits).

## PDF lesson or file?

| | **PDF lesson** | **File item** |
|---|---|---|
| How it opens | In the reader | Downloads |
| Counts towards progress | Yes | Yes |
| Can be read without leaving | Yes | No |
| Good for | A reading | A worksheet to fill in |

Use a PDF lesson for anything you want learners to read, and a file for anything they
need to keep.

## Common questions

<Accordions type="single">

<Accordion title="A file will not preview.">
Only images and videos preview in the file manager. Everything else downloads.
</Accordion>

<Accordion title="A learner says a PDF will not open.">
Check whether it is a PDF lesson or a file item — a file downloads, and on a phone that
depends on them having something to open it with. For a reading, use a PDF lesson.
</Accordion>

<Accordion title="Can learners read a PDF full screen?">
Yes, in the reader.
</Accordion>

<Accordion title="Does opening a PDF count as completing it?">
It depends on the item's completion rule. See
[Completion rules](/docs/knowledgebase/progress-grading/completion-rules).
</Accordion>

</Accordions>
