You can preview common file types directly in your platform. This lets you check that
you've got the right file — and that it looks correct — before you attach it anywhere.

## What you can preview

| Type | What you see |
|---|---|
| **Images** | The picture, shown full size |
| **PDFs** | The document, page by page |
| **Video** | A built-in player to watch the clip |
| **Audio** | A built-in player to listen |

Other file types (for example, slides or spreadsheets) may not preview in the browser.
For those, download the file to open it on your device.

## How to preview a file

1. Go to **Files & Media**.
2. Find the file you want to check.
3. Click it to open the preview.

The file opens right there — no need to download it first. Close the preview to return to
your library.

## Why preview first

- Confirm you picked the **right** file before attaching it to a course or page.
- Check that an image looks sharp and is the right shape.
- Make sure a video or audio file plays correctly from start to finish.
- Scan a PDF to confirm it's the final, correct version.

<Callout type="info">
Previewing is a quick quality check. Build the habit of previewing a file before you
attach it to a lesson, assignment, or website page — it saves fixing mistakes later.
</Callout>
