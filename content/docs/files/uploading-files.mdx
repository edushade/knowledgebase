Every image, video, PDF and document on your platform lives in the file manager. Upload
once, use anywhere.

<WhoCan roles="Admin, Instructor" />

## Four ways in

**Upload Files** opens the uploader, which takes files four ways:

| Way | For |
|---|---|
| **Choosing files** | The ordinary route. Several at once. |
| **Dragging and dropping** | The same, faster. |
| **Camera** | Taking a photo there and then. |
| **Screen Capture** | Recording your screen — **Record** and **Stop**. |

Screen capture is quietly useful: a two-minute walkthrough of a thing learners keep
asking about, recorded in the browser, with no editing software.

## What is allowed

Two settings, in <Path>Settings > Control Panel</Path> under **Media**:

| Setting | What it does |
|---|---|
| **Max upload file size (MB)** | The limit for your team. |
| **Max upload file size for learners (MB)** | A separate, usually smaller, limit for learners. |
| **Allowed file types** | A list of the types accepted. |

<Callout type="info">
Learners have their own size limit because they upload assignments. Set it to what a
real submission needs and no more — a limit that is too generous fills your storage
with phone video.
</Callout>

## After uploading

Files land in the current folder. From there you can **rename**, **move**, **delete**,
**download** and **preview** them, and a **Crop Image** tool handles the thumbnail that
is the wrong shape.

## Naming things

The file manager is shared, and a year in it is either usable or it is not. Three
habits:

1. **Name files for what they are**, not what the camera called them.
   `data-structures-week-1.mp4`, not `VID_20261104_143022.mp4`.
2. **Put them in folders** before you have hundreds.
3. **Upload once.** The same file in four courses should be one file, not four.

## Common questions

<Accordions type="single">

<Accordion title="An upload failed.">
Usually size or type. Check the limits in **Media** settings, and the allowed types
list.
</Accordion>

<Accordion title="A learner cannot upload their assignment.">
They are on the learner size limit, which is separate and lower. Raise it, or tell them
what the limit is.
</Accordion>

<Accordion title="Can I upload a whole folder?">
Select the files and upload them together; then organise them into a folder.
</Accordion>

<Accordion title="Where do videos go?">
The same library. How they play is a separate matter — see
[Video playback](/docs/knowledgebase/files/video-playback).
</Accordion>

<Accordion title="Can I replace a file and have every use update?">
Uploading a new version makes a new file. Replace the reference where it is used, or
keep the name and re-link.
</Accordion>

</Accordions>
