Uploading puts a file into your library so you can preview it and attach it anywhere on
your platform. You can upload many kinds of file, and large files are supported.

## What you can upload

| Type | Examples |
|---|---|
| **Documents** | Word files, slides, spreadsheets, text files |
| **PDFs** | Handouts, worksheets, e-books, certificates |
| **Images** | Photos, logos, thumbnails, banners |
| **Audio** | Lessons, recordings, podcasts |
| **Video** | Lectures, demos, intro clips |

Large files — like full-length lecture videos — upload reliably. You do not need to do
anything special; just pick the file and let it finish.

## How to upload a file

1. Go to **Files & Media** in your admin area.
2. Open the folder where you want the file to live (or stay in the main view).
3. Click **Upload**.
4. Choose one or more files from your device, or drag them onto the upload area.
5. Wait for each file to finish. A progress bar shows how it is going.

When the upload completes, the file appears in your library, ready to preview or attach.

## Uploading several files at once

You can select multiple files in one go. Each uploads on its own, so a slow file will
not hold up the others. You can keep working while uploads finish in the background.

## Tips

<Callout type="info">
Give files clear, descriptive names before you upload (for example,
`week-1-handout.pdf` instead of `scan001.pdf`). It makes them far easier to find later.
</Callout>

- For video and audio, upload the final version — you can always replace it by uploading
  a new file and attaching that one instead.
- If an upload is interrupted (for example, your internet drops), just try the file
  again.
- Some file types and sizes are limited for safety. See
  [Sharing and limits](/docs/knowledgebase/files/sharing-and-limits) if a file is
  refused.
