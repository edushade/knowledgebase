The file manager starts tidy and does not stay that way on its own. Twenty minutes
spent on structure in the first week saves hours later.

<WhoCan roles="Admin, Instructor" />

## Folders

**Create New Folder**, name it, and move files in. Folders nest, and a breadcrumb shows
where you are.

A structure that survives:

```
Courses/
  Data Structures/
    Videos/
    Handouts/
  IELTS Preparation/
    Videos/
    Audio/
Brand/
  Logos/
  Certificates/
Website/
  Hero images/
```

The principle: **folders by where a file is used**, not by what type it is. "Videos" at
the top level becomes four hundred files with no clue which course they belong to.

## Finding things

| Control | What it does |
|---|---|
| **Sort** | Name (A–Z), Name (Z–A), Newest First, Oldest First, Largest First. |
| **Folders First** / **Files First** | Which come at the top. |
| Grid or list view | Grid for images, list for everything else. |
| Breadcrumb | Where you are, and the way back. |
| Sidebar | The folder tree. |

**Largest First** is the one to use when storage is filling up. The answer is almost
always three videos nobody is using.

## Renaming and moving

Rename a file or folder in place, and move files between folders. A renamed file keeps
working wherever it is already used.

## Deleting

Deletion is permanent. Before you delete anything, check it is not in use — a file
removed from the library disappears from every lesson that showed it.

**Largest First**, then check each one, is the safe way to reclaim space.

## A yearly tidy

Once a year, before the new intake:

1. Sort by **Largest First** and deal with the top twenty.
2. Archive last year's course materials into a dated folder.
3. Delete the duplicates — the same handout uploaded four times by four people.

## Common questions

<Accordions type="single">

<Accordion title="I cannot find a file I uploaded.">
Check which folder you were in when you uploaded it. Sort by **Newest First** to find
it.
</Accordion>

<Accordion title="Does moving a file break the lessons using it?">
No. The file is the same file, wherever it sits.
</Accordion>

<Accordion title="Can I see where a file is used?">
Not from the library. Check before deleting anything you are not sure about.
</Accordion>

<Accordion title="Can two people organise the library at once?">
It is shared, so yes — which is a reason to agree the structure before everybody starts
making folders.
</Accordion>
