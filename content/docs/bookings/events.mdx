An event is a session people register for rather than book a slot in. A webinar, a
seminar, an orientation, an open day.

<Path>Teach > Events</Path>.

<WhoCan roles="Admin, Instructor" />

## Event or meeting plan?

| | **Event** | **Meeting plan** |
|---|---|---|
| Shape | One session, many people | A slot somebody books |
| Time | Fixed | Chosen by the invitee |
| People | Registrants | Invitees |
| Good for | Webinars, seminars, open days | Consultations, tutorials, office hours |

If the time is decided by you, it is an event. If the attendee picks, it is a meeting
plan.

## Setting one up

| Field | What it is |
|---|---|
| **Title**, **Description**, **Summary** | What it is. |
| **Event Type** | What kind. |
| **Thumbnail** / **Cover** | Its images. |
| **Categories** | For your catalogue. |
| **Speakers** | Who is presenting — the event's version of instructors. |
| **Start Time**, **End Date** | When. |
| **Medium Type** | Zoom, Google Meet, Teams, a link you supply, or **Offline** with a **Physical Address**. |
| **Meeting URL (Join Link)**, **Access Password**, **Joining Instructions** | How people get in. |
| **Max Participants Limit** | **0 means unlimited.** |
| **Registration Deadline** / **Registration End** | When registration closes. |
| **Status** | Draft or Published. |

### Recurring events

**Recurring Webinar** with a **Recurrence Frequency** — **Daily**, **Weekly**, **Monthly**
or **Yearly** — and **Max Occurrences**. A weekly open evening is one event rather than
fifty.

### During the event

| Setting | What it does |
|---|---|
| **Enable Chat** | Attendees can talk. |
| **Enable Q&A** | Attendees can ask questions. |

### Afterwards

**Webinar Status** covers **Live**, **Recorded**, **Completed** and so on, so a recorded
session can keep earning after the day.

## Participants

Each event has a **Participants** list: who registered, when they registered, and when
they joined.

| Action | What it does |
|---|---|
| **Register** | Add somebody yourself. |
| **Import Participants** | Upload a CSV — for a list you already hold. |
| **Remove participant** | Takes them off. Asks first. |

The import is the one worth knowing about: for an event promoted outside your platform,
you can bring the list in rather than typing it.

## Staff and pricing

An event has its own **Staff** screen, and its own **Pricing** — see
[Pricing](/docs/knowledgebase/selling-payments/pricing) with the entity type **Event**.
A free event still needs registration, which is how you get the list.

## What learners see

Events appear in the learner's **Event** area, with the ones they have registered for
and what is coming.

## Common questions

<Accordions type="single">

<Accordion title="Nobody can register.">
Check it is **Published**, that the registration deadline has not passed, and that the
participant limit is not reached.
</Accordion>

<Accordion title="Registrants have no joining link.">
Either no conferencing provider is connected, or the **Meeting URL** has not been
filled in for a medium you supply yourself. See
[Integrations](/docs/knowledgebase/bookings/integrations).
</Accordion>

<Accordion title="Can I charge for an event?">
Yes — price it as an **Event**. Free events still take registrations.
</Accordion>

<Accordion title="Can an event be part of a course?">
Not as a curriculum item. For a scheduled class inside a course, use a **Live** lesson —
see [Lesson types](/docs/knowledgebase/courses/lesson-types).
</Accordion>

<Accordion title="How do I know who actually attended?">
The participants list records when each person joined, as against when they registered.
</Accordion>

</Accordions>
