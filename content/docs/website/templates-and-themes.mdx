A theme is your site's look: its colours, its fonts, how round the corners are. It is
set once and every page follows.

<Path>Configure > Website</Path>, under design settings.

<WhoCan roles="Admin" />

## Presets

A preset is a complete ready-made look. Start from one — it is faster than choosing a
dozen colours, and the result is coherent. **Randomize preset** throws one up if you do
not know where to begin.

Then adjust what matters: your brand colour, and the fonts.

## Colours

Colours are set for **Light** and **Dark** separately, with a preview beside them so you
can see the result as you change it.

| Mode | What it is |
|---|---|
| **Light** | The light theme. |
| **Dark** | The dark theme. |
| **System** | Follows the visitor's own device setting. |

<Callout type="warn">
**Check both modes.** A brand colour that reads well on white can be invisible on dark,
and more than half your visitors will be on a phone set to dark.
</Callout>

## Fonts

| Setting | What it is |
|---|---|
| **Font Sans** | Your main typeface. |
| **Font Serif** | For anything set in a serif. |
| **Font Mono** | Monospace, for code. |
| **Letter Spacing** | Global spacing — `0em`, `0.05em`. |

### Fonts per language

You can **override fonts for specific languages** — "only set fonts that differ from the
defaults above".

This matters for a Bangla-first academy: the font that looks right in Latin script often
looks wrong in Bangla, and a dedicated Bangla font makes the whole site read better.
Leave the rest on the defaults.

## Shape

**Border radius** controls how round everything is, across every component at once. It
is a small setting that changes the whole feel — square for formal, round for friendly.

## Previewing

A live **Website Preview** sits beside the controls. **Refresh preview** reloads it, and
**Open in new tab** gives you the real thing at full size.

Look at the real site, not just the preview, before you settle — on a phone as well as a
laptop.

## Where the look comes from

Three layers, in order:

1. **The theme** — colours, type, shape. Everywhere.
2. **The blocks** — each section's own layout. See
   [Pages and blocks](/docs/knowledgebase/website/pages-and-blocks).
3. **Your logo and identity** — see
   [Your platform's identity](/docs/knowledgebase/account-people/your-platform-settings).

A site that feels like yours needs all three to agree.

## Common questions

<Accordions type="single">

<Accordion title="Our brand colour looks wrong in dark mode.">
Set a different value for dark. The two modes are configured separately for this reason.
</Accordion>

<Accordion title="Bangla text looks wrong.">
Set a Bangla font in the per-language overrides. The default sans is chosen for Latin
script.
</Accordion>

<Accordion title="Can one page look different from the rest?">
The theme is site-wide. A page differs by the blocks it uses, not by its own colours.
</Accordion>

<Accordion title="Can I switch dark mode off?">
Set the mode rather than leaving it to **System** if you only want to support one.
</Accordion>

<Accordion title="The preview does not match the live site.">
**Refresh preview**, or open it in a new tab. The preview can lag a change by a moment.
</Accordion>

</Accordions>
