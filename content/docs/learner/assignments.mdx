**Assignment** in the learner's menu collects everything they have to hand in.

<WhoCan roles="Learner" />

## Three tabs

| Tab | What is in it |
|---|---|
| **Pending Assignments** | Still to do. |
| **Previous Assignments** | Submitted. |
| **Published Results** | Marked and released. |

Each says so plainly when empty — "You don't have any pending assignments at the
moment."

## What a card shows

| Field | Notes |
|---|---|
| **Assigned At** | When it was set. |
| **Starts At** / **Ends At** | Its window. |
| **Deadline** | When it is due. |
| **Expired** | The window has closed. |
| **Submitted `{time}` ago** | For work handed in. |
| **Earned Points** | Once marked. |
| **Not Started** | Nothing submitted. |
| **Submit Assignment** | The button to act. |

## Where the deadline comes from

**The deadline is the drip schedule's lock date on the assignment item**, not a field on
the assignment itself. An assignment with no lock date has no deadline, whatever the
instructions say.

That is the single most common setup mistake with assignments — see
[Assignments](/docs/knowledgebase/assessments/assignments).

## Why a result is not there

**Published Results** only shows work that has been marked **and** released. Two
different waits:

1. **Nobody has marked it.** It sits in your queue — see
   [Assignment submissions](/docs/knowledgebase/assessments/assignment-submissions).
2. **It is marked but held.** Scores are waiting for a release time.

Either way, the learner sees nothing and assumes the first.

## Common questions

<Accordions type="single">

<Accordion title="A learner says there was no deadline.">
There probably was not. Check the lock date on the assignment's drip schedule.
</Accordion>

<Accordion title="They cannot submit.">
The window has closed, they have used their attempts, or their file is over the learner
upload limit. See [Learner uploads](/docs/knowledgebase/files/learner-uploads).
</Accordion>

<Accordion title="They submitted and see no mark.">
It has not been marked. A submission is not a grade.
</Accordion>

<Accordion title="Can a learner resubmit?">
Up to the assignment's maximum attempts.
</Accordion>

<Accordion title="Where do they see your feedback?">
With the result, once it is published. Internal comments are never shown to them.
</Accordion>

</Accordions>
