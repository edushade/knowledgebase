description: "Enroll a single learner yourself, or add a whole roster at once."
---

Sometimes you need to put learners into an offering yourself — a single student you're
adding by hand, or an entire class list. You can do both.

## Enroll a single learner

Use this when you want to add one specific person.

1. Go to **Admin → Enrollments** (or open the offering and use its **Learners** tab).
2. Choose **Enroll learner**.
3. Pick the **offering** (course, learning path, or cohort) and the **learner**.
4. Set any per-enrollment options (see below).
5. Save.

<Callout type="info">
Enrolling a learner yourself can **bypass the public enrollment window**. This lets you
add someone even when self-enroll is closed — useful for late joiners or special cases.
</Callout>

## Bulk enroll a roster

Use this when you want to add many learners at once.

1. Go to **Admin → Enrollments** and choose the **bulk enroll** option.
2. Pick the offering.
3. Upload your list of learners (a roster).
4. Confirm.

When the bulk enrollment finishes, you get a **per-learner summary** showing who was
enrolled successfully and who could not be added (for example, someone already enrolled, or
a name that didn't match an account). You can fix the failures and try those again.

## Per-enrollment options

Whether you add one learner or many, each enrollment can carry these settings:

| Option | What it does |
|---|---|
| **Access window (expiry date)** | The date access ends for this learner. |
| **Allow extensions** | Whether their access window can be extended later. |
| **Notifications** | Turn this learner's notifications on or off. |

## Re-enrollment

You can only re-add a learner whose previous enrollment was **cancelled** or **expired**. A
learner who is currently **active**, **completed**, or **suspended** is treated as already
enrolled. See the status table in
[How learners enroll](/docs/knowledgebase/enrollment-access/how-learners-enroll#enrollment-statuses).

## Giving partial access

When you enroll learners, you can also limit them to **part** of an offering — for example,
only one semester or one purchased section. You can set this during enrollment, or adjust it
for many learners later. See
[Partial access](/docs/knowledgebase/enrollment-access/partial-access).

## Common questions

**Can I enroll someone before an offering is published?**
The offering must be published for learners to actually use it. Publish it first, then add
learners.

**A few rows failed in my bulk upload — did the rest still go through?**
Yes. Bulk enrollment processes each learner on its own and reports each result, so the
successes are saved even if some rows fail.
