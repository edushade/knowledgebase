A template is a message you keep. Write "payment confirmation" once and every payment
confirmation reads the same.

<Path>Notifications > Templates</Path>.

<WhoCan roles="Admin" />

## One template, several channels

A template can carry a version for each channel it supports — the same message, written
properly for each:

| Channel | What it holds |
|---|---|
| **Email** | A **subject line** and a body, with formatting. |
| **SMS** | 160 characters. "Keep it short and concise." |
| **Push** | A title and a line. |
| **In-app** | A title and a message. |
| **Slack**, **Discord**, **Telegram**, **WhatsApp** | Each in its own format. |

Select which channels the template supports, then write each one. An SMS that is a
truncated email reads like a mistake.

## Tokens

Tokens fill in per recipient:

| Token | Becomes |
|---|---|
| `{{user_name}}` | Their name |
| `{{user_email}}` | Their email |
| `{{course_name}}` | The programme |
| `{{due_date}}` | The date |
| `{{amount}}` | The amount |
| `{{payment_method}}` | How they paid |

A subject of `Payment Confirmation - {{course_name}}` arrives as "Payment Confirmation -
Data Structures".

<Callout type="warn">
Send yourself a test before using a template in anger. A token that does not resolve
arrives as literal text, and "Dear &#123;&#123;user_name&#125;&#125;" is the sort of
thing a learner screenshots.
</Callout>

## Category

| Category | For |
|---|---|
| **Transactional** | Payments, verification, enrolment. Things people need. |
| **Marketing** | Offers and promotion. Learners can switch these off. |
| **Announcement** | News. |
| **System Announcement** | Platform-level notices. |

Categorise honestly. A learner who switched marketing off and receives an offer labelled
transactional has been ignored, and they will notice.

## Starting from an existing one

**Choose an Email Template** offers a starting point — *"select a template to get
started; you can customise it after loading"*. Load one and edit rather than starting
from an empty page.

The email editor itself is configured in <Path>Settings > Control Panel</Path> under
**Email Editor**.

## Templates worth having

| Template | When it goes |
|---|---|
| Welcome | They enrol |
| Payment confirmation | They pay |
| Payment reminder | An instalment is due |
| Course starting | A batch begins |
| Assignment due | Two days before |
| Results published | A result is released |
| Certificate earned | They qualify |
| Access ending | Seven days before |

Writing these eight once is most of your communication for the year.

## Common questions

<Accordions type="single">

<Accordion title="A token came out as literal text.">
The token name is wrong, or it has no value for that recipient. Test before sending.
</Accordion>

<Accordion title="Can I use one template on several channels?">
That is what they are for. Select the channels and write each version.
</Accordion>

<Accordion title="My email looks wrong on a phone.">
Send yourself a test and open it on one. Most of your learners will read it there.
</Accordion>

<Accordion title="Can templates be in more than one language?">
Write the version your audience reads, and use a separate audience and template per
language where you teach in two.
</Accordion>

<Accordion title="Where do I see whether it arrived?">
[Delivery and analytics](/docs/knowledgebase/communication/delivery-and-analytics).
</Accordion>
