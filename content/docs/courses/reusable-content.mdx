title: "Reusable Content"
description: "Four ways to use the same material twice, and which one to pick."
---

There is no single "reuse" button. There are four different mechanisms, each with its
own behaviour, and picking the wrong one is how a course ends up quietly out of step
with its copy.

<WhoCan roles="Admin, Instructor" />

## The four ways

| Way | What you reuse | Does the copy stay linked? |
|---|---|---|
| **A quiz in several courses** | One quiz | **Yes** — it is the same quiz |
| **A course in several learning paths** | One whole course | **Yes** — it is the same course |
| **The Content Bank** | Questions, lessons, assignments | **No** — you take a copy |
| **Export and import** | A whole course | **No** — you get a separate course |

## Shared, not copied

**A quiz added to two courses is one quiz.** Edit a question and both courses change.
Learners' attempts are kept per enrolment, so marks do not leak between courses — but
resetting a shared quiz for a learner affects it everywhere they have taken it, and the
reset asks you to confirm that.

**A course inside a learning path is the same course.** Rename it and every path
containing it shows the new name. If you need a different version for one path, make a
second course.

<Callout type="warn">
Shared means shared. Before you edit a quiz, check whether it is used elsewhere — a
tidy-up in one course can change an exam another course is about to sit.
</Callout>

## Copied, not shared

**The [Content Bank](/docs/knowledgebase/courses/content-bank)** holds questions,
lessons and assignments. When you pull one into a course, the course gets its own copy.
Editing the bank afterwards changes nothing in courses that already took it, and editing
the course's copy changes nothing in the bank.

That is deliberate: a question a cohort has already answered must not change under them.

**[Export and import](/docs/knowledgebase/courses/importing-and-exporting)** produces a
whole separate course. It arrives as a draft and has nothing to do with the original
from then on.

## Duplicating a batch

A batch has its own route: **Re-use from Existing** when creating one, which copies the
batch's settings and — if you say **Yes, include all content** — its content too. See
[Cohorts and batches](/docs/knowledgebase/courses/cohorts).

## Which to choose

- **The same exam in two courses** → add the same quiz to both. One place to fix a
  mistake.
- **A question you will adapt** → the Content Bank. You want the copy to drift.
- **Next year's intake of a running batch** → **Re-use from Existing**.
- **A course on another academy you run** → export and import.
- **Three courses sold together** → neither. That is a
  [bundle](/docs/knowledgebase/selling-payments/bundles).

## Common questions

<Accordions type="single">

<Accordion title="How do I know whether a quiz is used anywhere else?">
Open the quiz and look at where it appears — the quiz's own screens list the programmes
it belongs to. Treat any quiz you did not create this week as shared until you have
checked.
</Accordion>

<Accordion title="I reset a learner's quiz and it reset in another course too.">
Because it is the same quiz. The confirmation before a reset on shared content says
which programmes are affected — it is worth reading. See
[Attempts and retakes](/docs/knowledgebase/assessments/attempts-and-retakes).
</Accordion>

<Accordion title="Can I copy one section from one course to another?">
Not as a section. Save the pieces to the Content Bank and rebuild the section in the
other course, or export the whole course and strip what you do not need.
</Accordion>

<Accordion title="If I delete a course that is inside a learning path, what happens?">
The path loses that content. Take the course out of the path first, so you can see what
the path looks like without it before the deletion is permanent.
</Accordion>

</Accordions>
