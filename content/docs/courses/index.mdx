This is where the teaching lives. A **course** is the unit; a **batch** is a scheduled
run of one; a **learning path** strings several courses into one programme. Everything
else on this page is what goes inside them.

New here? Start with [Creating a course](/docs/knowledgebase/courses/creating-a-course) —
it is the three-step walkthrough from empty form to published page.
