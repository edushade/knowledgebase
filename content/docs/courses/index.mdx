This is where you build everything your learners will study. A course can be one short
class or a deep, multi-part program. You can also group several courses into a guided
learning path, or run a scheduled group called a cohort.

## The three things a learner can enroll in

Learners join one of three kinds of offering. They all use the same content builder, so
once you learn one, you know them all.

| Offering | What it is | Good for |
|---|---|---|
| **Course** | The main teaching unit — lessons, quizzes, assignments, and files, organized into sections. | A single subject or class. |
| **Learning path** | A higher-level track that groups several courses (and other items) into one guided sequence. | A multi-course diploma or program. |
| **Cohort** | A scheduled run of a course or learning path, with start and end dates and a group of learners moving together. | Live or time-bound classes that start on a set date. |
