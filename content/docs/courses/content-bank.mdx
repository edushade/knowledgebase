The Content Bank is where material lives when it does not belong to one course. Write a
question once, keep it here, and use it in next year's exam as well as this year's.

## The three collections

Open <Path>Content Bank</Path> and pick a collection on the left:

| Collection | What it holds |
|---|---|
| **Question** | Quiz questions of every type, with their marks and answers. |
| **Lesson** | Lessons that are not tied to a course. |
| **Assignment** | Assignment briefs ready to be set again. |

## Working with questions

The question list shows, for each one: the question itself, its **Type**, its **Marks**,
whether it is **Required**, whether it is **Auto Grade**d, and when it was made. Two
filters sit above the table:

- **Question Type** — narrow to multiple choice, true/false, matching and so on.
- **Auto Gradable** — show only questions the system can mark by itself, or only the
  ones a person has to read.

**Add Question** writes a new one straight into the bank. The question types and what
each needs are covered in [Question types](/docs/knowledgebase/assessments/question-types).

## Using banked content in a course

From a quiz, choose to add questions from the bank rather than writing them in place.
From the course builder, a lesson or assignment can be started from a banked one. See
[Reusable content](/docs/knowledgebase/courses/reusable-content).

<Callout type="info">
A banked item is a *source*, not a live link. Once it is in a course it is that course's
copy — editing the bank afterwards does not rewrite courses that already used it, and
editing the course copy does not change the bank.
</Callout>

## Good to know

- **The bank is shared across your whole academy.** Anyone who can build a course can
  draw from it, which is the point — and a reason to keep the titles tidy.
- **Deleting from the bank does not remove copies already in courses.** Those are the
  course's own, and keep working.
- **Status.** Banked items carry **Draft**, **Published** or **Archived**. Archive the
  ones you have stopped using rather than deleting them, so an old exam can still be
  reconstructed.

## Common questions

<Accordions type="single">

<Accordion title="How do I get my existing questions into the bank?">
Write them in the bank directly with **Add Question**, or build a quiz and save its
questions to the bank. There is no spreadsheet import for questions; courses and
learning paths have an import, questions do not. See
[Importing and exporting](/docs/knowledgebase/courses/importing-and-exporting).
</Accordion>

<Accordion title="I edited a banked question. Why did the quiz not change?">
Because the quiz holds its own copy, taken when the question was added. That is
deliberate — a quiz learners have already sat must not change under them. Update the
quiz's copy directly, or remove the question and add the new version.
</Accordion>

<Accordion title="What does Required mean on a question?">
That a learner cannot submit the quiz leaving it blank. It has nothing to do with marks.
See [Question types](/docs/knowledgebase/assessments/question-types).
</Accordion>

<Accordion title="Who can see the bank?">
Anyone whose role lets them see course content. If you need a group who can build
courses but not touch the shared bank, that is a permission change — see
[Roles and permissions](/docs/knowledgebase/account-people/people-and-roles).
</Accordion>

</Accordions>
