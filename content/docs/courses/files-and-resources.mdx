description: "Handouts, worksheets and downloads — the two ways to attach them, and which one counts towards progress."
---

There are two ways to give learners a file, and they behave differently. Choosing the
wrong one is why a worksheet sometimes counts towards a learner's progress when you did
not mean it to — or does not when you did.

<WhoCan roles="Admin, Instructor" />

## The two ways

| | **Attachment on a lesson** | **File item in the course** |
|---|---|---|
| Where it appears | Listed under that lesson | Its own row in the outline |
| Counts towards progress | No | Yes |
| Can be dripped or locked on its own | No | Yes |
| Can have its own completion rule | No | Yes |
| Good for | A worksheet that goes with a video | A dataset the whole course works from |

**Attachments** are set when you edit a lesson, in its **Attachments** field. They are
extras hanging off the teaching.

**File items** are added with **+ File** in the course builder, or from the **⋯** menu
on an item. They are part of the course the same way a lesson is.

## Where files come from

Both pull from your file library, so a file uploaded once can be used in several places.
See [Uploading files](/docs/knowledgebase/files/uploading-files) and
[Organizing files](/docs/knowledgebase/files/organizing-files).

## What the learner sees

An attachment appears as a download under the lesson. A file item appears in the outline
with the rest of the course and opens in the viewer, where it can be previewed before
downloading — see [Previewing files](/docs/knowledgebase/files/previewing-files).

## Good to know

- **A file item that is not published is invisible**, exactly like an unpublished lesson.
- **File items can be excluded from what counts.** Whether a file has to be opened for a
  learner to be "done" is a completion rule, set from the item's **⋯** menu. See
  [Completion rules](/docs/knowledgebase/progress-grading/completion-rules).
- **A PDF you want learners to read in the page** is better as a **PDF lesson** than a
  file — it opens in a reader instead of downloading.

## Common questions

<Accordions type="single">

<Accordion title="A worksheet is pushing everyone's progress down.">
It is a file item, and it counts. Either make it an attachment on the lesson it belongs
to, or change its completion rule so it does not have to be opened.
</Accordion>

<Accordion title="Can I stop learners downloading a file?">
Not for a file item — a download is a download. For material you do not want leaving the
platform, use a PDF lesson, which opens in the reader, or put the content in a text
lesson.
</Accordion>

<Accordion title="How big can a file be?">
Your academy has an upload limit and a total storage allowance. See
[Sharing and limits](/docs/knowledgebase/files/sharing-and-limits).
</Accordion>

<Accordion title="Can learners upload files to me?">
Through an assignment, yes — that is what an assignment submission is. See
[Assignment submissions](/docs/knowledgebase/assessments/assignment-submissions) and
[Learner uploads](/docs/knowledgebase/files/learner-uploads).
</Accordion>

</Accordions>
