Two different questions live in this section. **Progress** asks *did they do it?*
**Grading** asks *how well?* A learner can be 100% through a course and have no result
at all, because nothing has been marked yet.

If a mark looks wrong, start with
[Learner grades](/docs/knowledgebase/progress-grading/learner-grades) — it walks down
the four levels a result is built from.

## Two settings worth knowing by heart

Between them, these explain most "the mark is wrong" questions:

| Setting | What it changes |
|---|---|
| **Treat Ungraded Items as Zero** | Off, a learner is marked only on what has been marked — so one good quiz can read as a near-perfect course. On, unmarked work counts as zero. |
| **Rounding** | A grade is matched to its band *after* rounding, so this setting moves the pass line. |
