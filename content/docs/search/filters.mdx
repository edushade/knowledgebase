Filters let a learner cut a page of results down to the few that fit. They appear beside
search results and in your catalogue.

<WhoCan roles="Learner" />

## What learners can filter by

| Filter | Where it comes from |
|---|---|
| **Category** | The course's categories. |
| **Tags** | Its tags. |
| **Difficulty** | Beginner, Intermediate, Advanced. |
| **Language** | The course's language. |
| **Type** | Course, learning path, bundle, product, event. |
| **Access type** | How access is granted. |

Each filter shows how many results it would leave, so a learner can see before they
click that "Advanced" has two.

## Filters are only as good as your data

<Callout type="warn">
**Inconsistent values are what break filters.** "IELTS", "ielts" and "I.E.L.T.S." are
three tags and one useless filter. A course with no difficulty set does not appear under
any difficulty.
</Callout>

Three habits that keep them working:

1. **Agree the tag names** and write them down.
2. **Set difficulty and language on every course**, even when it feels obvious.
3. **Keep categories few.** A filter with thirty options is a list, not a filter.

## Filters and search together

A learner usually searches first and filters second: "English", then Beginner, then
Bangla. That only helps if the courses carry those values — a search that returns
fifteen results of which eleven have no difficulty set makes the filter useless.

## Common questions

<Accordions type="single">

<Accordion title="A course is missing from a filtered list.">
It has no value for that filter. A course with no difficulty set does not appear under
Beginner, Intermediate or Advanced.
</Accordion>

<Accordion title="Can I add our own filter?">
The filters above are what exists. Products can carry their own
[taxonomies](/docs/knowledgebase/selling-payments/products-catalog) for attributes
specific to them.
</Accordion>

<Accordion title="Can I change the order of filters?">
How your catalogue listings are laid out is part of your website — see
[Pages and blocks](/docs/knowledgebase/website/pages-and-blocks).
</Accordion>

<Accordion title="We have duplicate tags.">
Pick one spelling, re-tag, delete the rest. See
[Categories and tags](/docs/knowledgebase/account-people/categories-and-tags).
</Accordion>

</Accordions>
